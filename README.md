# Qwen3-0.6B 微调考核 · 第一部分

以 **Qwen3-0.6B** 为基座微调，在**保持通用能力可控**的前提下，**同步提升安全对齐与数学推理**。

**打分**：`总分 = 安全 × 40% + 数学 × 30% + 通用 × 30%`（三个测试集不公开）。
**约束**：基座固定为 [Qwen/Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B)，参数量 0.6B 不可变。提交：模型 + 一页报告。

## 🎯 策略要点（基于基线 + 调研）

1. **安全优先**：15.1% 起点最低、权重最高 → 第一优先级，用 Aegis refusals 训。
2. **非 thinking / 短 CoT**：0.6B 长思考有"山谷效应"，直接分步答更准更快 → 数学数据用短 CoT。
3. **小而精，不堆量**：小模型大数据量会"训歪"（有实证）→ 每任务几千条起步。
4. **混合训练防遗忘**：三类数据一次性混训（不顺序训）+ 1~5% replay 守通用。
5. **数据配比起步 40:30:30**，小学习率 + 早停，全参 vs LoRA 对照。
